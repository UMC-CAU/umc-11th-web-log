6주차 API 실제 HTTP 검증 기록

Spring Boot demo 프로필 · H2 임시 DB · 2026-11-04T06:15:56.740Z

실행 중인 서버에 전송한 실제 HTTP 요청·응답입니다. Postman 캡처나 MySQL 실행 결과가 아닙니다. 비밀번호는 실습용 더미 값이며 회원가입 응답에는 포함되지 않습니다.

1. 회원가입 성공 HTTP 201

POST http://127.0.0.1:18086/members

요청 본문

{
  "email": "week6-1793772956124@example.com",
  "password": "Umc!1234",
  "nickname": "회원72956124"
}

실제 응답

{
  "isSuccess": true,
  "code": "COMMON201",
  "message": "회원가입에 성공했습니다.",
  "result": {
    "memberId": 3,
    "email": "week6-1793772956124@example.com",
    "nickname": "회원72956124"
  }
}

2. 이메일 형식 검증 실패 HTTP 400
